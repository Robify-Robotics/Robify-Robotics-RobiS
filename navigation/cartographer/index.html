    🧭 Cartographer 2D Mapping and Navigation

    RobiS supports the Cartographer SLAM algorithm developed by Google. Cartographer offers higher mapping accuracy and integrated localization, but it requires more computational power.

    🔧 1. Launch device driver

    ./autoware.ai/open.sh   # start docker

    Inside docker run:

    source catkin_ws/devel/setup.bash
roslaunch robot_start robot_start.launch

    🗺️ 2. Start Cartographer 2-D laser mapping (new terminal)

    ./autoware.ai/open.sh   # start docker

    Inside docker run:

    source catkin_ws/devel/setup.bash
roslaunch robot_start carto_2d_mapping.launch

    👀 3. Open rviz visualization (new terminal)

    rviz

    Load the preset:

    /home/robify/catkin_ws/src/robot_start/rviz/cartographer_2d_mapping.rviz

    Drive the robot in manual mode until the map is complete.

    💾 4. Save the map (new terminal)

    ./autoware.ai/open.sh   # start docker

    Inside docker run:

    source catkin_ws/devel/setup.bash
sh catkin_ws/src/robot_start/sh/save_map.sh

    After saving, stop the Cartographer mapping terminal (Ctrl-C).

    🧭 5. Launch navigation

    ./autoware.ai/open.sh   # start docker

    Inside docker run:

    source catkin_ws/devel/setup.bash
roslaunch robot_start teb_navigation_slam.launch

    🎯 6. Open rviz for navigation (new terminal)

    rviz

    Load the preset:

    /home/robify/catkin_ws/src/robot_start/rviz/cartographer_2d_navigation.rviz

    After setting pose with 2D Pose Estimate, use 2D Nav Goal to click any spot for point-to-point navigation (switch remote to upper-computer mode).

    Please refer to the accompanying video.
